# 3.1.1.0 実装記録

## 実装内容

- `hado_share.js`に8つのコピー・共有機能を集約した。
- `hado_share.css`に共有操作列と受信確認画面の表示を分離した。
- 一覧コピーは検索条件を先頭に置き、各行へカテゴリを付加した。数値検索時だけ該当値を併記する。
- 部隊共有文は、武将ごとに侍従名・侍従位置・武器・防具・文物を1行で出力する。
- 軍馬共有文は、通常技能を最大3件、各技能レベル付きで出力する。
- 詳細リンクはカテゴリと正規IDを使い、IDがないデータは名称を代替キーにする。
- 共有リンクは圧縮可能な環境ではdeflate-rawを使い、未対応環境ではBase64URLへ安全にフォールバックする。
- 部隊・軍馬の受信は追加専用とし、既存データを変更しない。
- 起動データの読込完了前に受信確認画面を出さないよう待機条件を設けた。

## 変更ファイルと責務

- `hado_share.js`: コピー文、共有URL、復元、追加専用インポート
- `hado_share.css`: 共有ボタンと確認画面
- `index.html`: 外部資産の読込だけを追加
- `hado_core.js`: 要素参照、表示入口、ビルド情報
- `hado_status_effects.js`: 一覧コピーを新仕様へ委譲
- `hado_bootstrap.js`: 起動時自己検査を新しいボタン名へ更新
- `hado_version.js` / `HADO_DEV_INFO.json`: `3.1.1.0 r204` Preview識別
- Preview workflow・検証スクリプト・回帰テスト: 新しいブランチと資産を検証対象へ追加
