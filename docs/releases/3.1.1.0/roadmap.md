# 3.1.1.0 コピー・共有機能ロードマップ

## 目的

検索結果、内容詳細、部隊編成、軍馬編成を、用途に合った読みやすい文章または再現用リンクとして共有できるようにする。

## 対象機能

1. 検索結果: `一覧コピー`
2. 検索結果: `検索リンクコピー`
3. 内容詳細: `詳細データコピー`
4. 内容詳細: `項目リンクコピー`
5. 部隊編成: `編成共有コピー`
6. 部隊編成: `新規部隊作成リンクコピー`
7. 軍馬編成: `軍馬共有コピー`
8. 軍馬編成: `新規軍馬作成リンクコピー`

## 共有リンクの安全方針

- URLは単一の`share` GETパラメータで表現する。
- 検索リンクは検索条件を復元する。
- 部隊・軍馬リンクは確認画面を表示してから、新規データとして追加する。
- 既存の部隊、軍馬、軍馬配置は上書きしない。
- 受信側に存在しない項目は未設定にし、不足内容を明示する。
