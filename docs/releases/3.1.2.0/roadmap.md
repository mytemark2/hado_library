# 3.1.2.0 兵科技能検索ロードマップ

## 目的

クローラーが`hadou_generals.json`へ収録する`兵科`技能を、他の検索カテゴリと同じ操作で検索・閲覧できるようにする。

## 実装範囲

1. 通常検索のカテゴリへ`兵科`を追加する。
2. `troop_effects`契約を検索項目へ正規化し、名称・兵科・付与条件・効果文から検索可能にする。
3. 一覧と内容詳細で兵科、付与条件、効果を確認可能にする。
4. Clause Shadowの計算・診断ログは残し、比較カードだけをPreviewを含む利用者画面から非表示にする。
5. 表示バージョンを`3.1.2.0 r207`に統一する。

## リリース方針

- 開発ブランチ: `feature/app-3.1.2.0`
- 開発Preview: `3.1.2.0 r207`
- 通常Pushを起点とする自動Preview同期を使用する。
- 正式版への反映は、Preview確認後の明示承認まで行わない。
