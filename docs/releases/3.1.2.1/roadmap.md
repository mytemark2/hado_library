# 3.1.2.1 修正版ロードマップ

## 目的

状態変化検索の最大レベル・全データ検索で、参照技能由来の状態変化を持つ武将も検索対象に含める。

## 対応範囲

- 個別状態変化検索の最大レベル判定で、公開索引の所有者情報を補完ソースとして統合する。
- 全データ検索・最大レベルの範囲に限定し、初期段階や保存データ検索の意味は変えない。
- 部隊段階を切り替えたときも結果を再評価する。
- LR張角「感電回避」を回帰ケースとして固定する。

## 完了条件

- ローカル総合検証に合格する。
- 開発ブランチへのPRを通じてPreviewへ自動同期する。
- Previewで版・マーカー・対象検索結果を実操作確認する。
- 利用者の対象commit明示承認後にのみ正式版へ反映する。
