# 3.0.2.0 r170 ロードマップ

## 目的

タグ一覧から個別の状態変化を指定し、その状態変化を持つ武将・戦法・技能・装備等を横断検索できるようにする。

## 実装範囲

- `状態変化:<名称>` タグを状態変化マスター全件から生成する。
- 品質監査済み関連リンクの所有者へ同じタグを付与する。
- 状態変化グループを技能グループの直前へ配置する。
- 能力変化の内部名は状態変化検索と同じ表示名で見せる。
- 通常検索、状態変化検索、型検索、PC、スマホで同じタグ条件を使用する。
- 旧クローラー生成データを読み込んだ場合も関連リンクから互換構築する。
- PC・スマホChromeとも入力確定だけではタグを追加せず、候補のタップ／クリック、またはキーボードで候補を選択した場合だけ追加する。
- 候補表示時も入力欄を16px以上に保ち、ページ拡大・横方向のレイアウト崩れを起こさない。
- 候補検索用の正規化文字列と並び順を索引構築時に事前計算し、入力時の再正規化を行わない。

## 完了条件

206状態変化、正規所有者関係、グループ順、表示名入力、AND/OR条件、PC/スマホ表示、IME入力後の候補表示、未選択Enterで未登録、候補のタップ／クリック・矢印キー選択、Preview配信を検証する。
