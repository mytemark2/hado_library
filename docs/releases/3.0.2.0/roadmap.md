# 3.0.2.0 r167 ロードマップ

## 目的

タグ一覧から個別の状態変化を指定し、その状態変化を持つ武将・戦法・技能・装備等を横断検索できるようにする。

## 実装範囲

- `状態変化:<名称>` タグを状態変化マスター全件から生成する。
- 品質監査済み関連リンクの所有者へ同じタグを付与する。
- 状態変化グループを技能グループの直前へ配置する。
- 能力変化の内部名は状態変化検索と同じ表示名で見せる。
- 通常検索、状態変化検索、型検索、PC、スマホで同じタグ条件を使用する。
- 旧クローラー生成データを読み込んだ場合も関連リンクから互換構築する。

## 完了条件

206状態変化、正規所有者関係、グループ順、表示名入力、AND/OR条件、PC/スマホ表示、Preview配信を検証する。
