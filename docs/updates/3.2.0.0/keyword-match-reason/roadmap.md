# 3.2.0.0 割込み — キーワード一致理由表示 Roadmap

## 目的

通常検索でキーワードを指定した際、各検索結果へ実際に一致した名称または本文の一文を表示し、結果を開く前に採用理由を判断できるようにする。

## 実装範囲

- 通常検索の名称一致は、名称に一致したことを一文で表示する。
- 全文検索は、検索対象として許可されたsection・table・rawデータから最初の一致文を表示する。
- 長文はキーワード周辺へ安全に短縮し、表示時にHTMLエスケープする。
- 空検索、状態変化検索、型検索には追加表示しない。
- 既存の検索判定、検索件数、並び順、パラメータ理由は変更しない。

## 完了条件

- 名称一致、本文一致、長文、安全なHTML表示、空検索を自動回帰で確認する。
- App Validationが合格する。
- Previewで表示版、marker、実際の一致理由表示を確認する。
- 正式公開は行わない。
