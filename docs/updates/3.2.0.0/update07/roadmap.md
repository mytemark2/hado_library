## 利用者の操作

1. 部隊一覧を名前・配置武将/侍従/参軍・主将の兵科・型・メモで絞り込む。空白区切りはAND。解除で元の一覧へ戻る。編集中の部隊は変更しない。
2. 「2編成を比較」から全グループを対象にA/Bを選ぶ。同じ名前でもグループ・主将・兵科・型で識別する。
3. 変更箇所を先に確認し、必要なら評価根拠や共通部分を展開する。スマートフォンも同じ操作を提供する。

## 設計境界

- 比較は読み取り専用。比較画面を閉じても編集対象・保存内容・更新日時・評価履歴・候補トレイ・dirty状態は変更しない。
- 武将5枠、侍従と位置、装備3枠、参軍5枠、陣形・配置場所、兵器/武装とレベル・異民族武将、型、メモを項目ごとに比較する。
- 現在の表示モード・保存データ・共通軍馬という同一条件で既存評価を再計算する。正規化に副作用のある既存ヘルパーは切り離した入力で実行し、例外時も元の参照を復元する。編成に記録された評価は別表示し上書きしない。未保存の編集がある場合は現在の編集内容を比較する。
- 評価の型が異なる場合は単純な合計差による優劣を表示しない。算出不可を0点と誤認させない。
- 軍馬配置は同一保存データ内で共通。最大3技能とLv・固有技能を共通情報に表示し、部隊差分に数えない。保存schemaや軍馬配置方式を変更しない。
- 一覧は名前・主将/兵科・型/保存評価を優先。更新日時・兵器/武装はtitleおよび選択後の既存詳細で確認する。
- 既存共有、保存、Export/Import、検索・詳細・編成の操作を維持する。
- 公開HTTPS Previewを必須ゲートとする。今後の実機確認範囲は[全体ロードマップ](../roadmap.md)のUpdate08を参照。
