## 実施手順

1. 作業開始時点のmain HEAD、正式表示版、開発ブランチ、Preview同期設定を確認する。
2. クローラーの既存取得記録と完了ログを確認し、同じ取得を不必要に再実行しない。
3. 最新取得データの識別子、件数、更新日時、生成元commitを記録する。
4. 直前の検証済みデータとの差分をエンティティ種別・識別子単位で分類する。
5. 一次JSONから派生JSONへの変換・参照関係・ID一意性・カテゴリ対応を監査する。
6. 検索、詳細、所有者検索における追加データの露出と既存データの回帰を確認する。
7. 未分類差分や矛盾は推測で補完せず、根拠・影響・要確認事項として登録する。
8. Update02以降の対象と受入テストを確定する。
