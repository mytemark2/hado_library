## 既存機能と今回の実装

既存の3.1.1.0実装に武将・侍従位置・装備の同一行コピー、軍馬最大3技能、文章コピーと新規作成リンクの別ボタンが存在する。これらを維持し、次を補う。

1. 文章を武将・参軍・兵器/武装・軍馬に区切り、軍馬能力・固有技能を追加する。
2. 軍馬技能を枠順で最大3件表示し、未設定の軍馬枠も明記する。
3. 保存データを書き戻す軍馬getterを共有処理から除き、読み取り専用snapshotを使用する。
4. 新規部隊作成リンクに軍馬参照snapshotを含め、追加前に共有内容を確認する。
5. 軍馬は保存データ内の全編成共通であるため、リンクから部隊を追加しても登録軍馬・配置は変更しない。確認画面にこの範囲を明記する。
6. 受信側にない参軍も不足一覧へ出し、未設定で新規作成する。既存部隊は上書きしない。
7. schema v1と旧リンクを維持し、軍馬情報を持たない旧リンクは「含まれていません」と区別する。

保存形式・派生JSON・軍馬の編成別永続化は変更しない。共有のためにクローラーを再取得しない。
