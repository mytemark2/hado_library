## 1. 開発目的

新しい武将・兵科・技能などが追加され続けても、取得データが検索・詳細・編成へ漏れなく反映され、利用者が条件や効果を理解しやすく、保存した編成を安全に比較・共有できる状態を目指す。

本開発は、次の順序で進める。

1. データの追加・変更を監査し正確性を確立する。
2. 兵科・技能・所有武将をつなぐ検索導線を整える。
3. データ更新の差分と反映状態を可視化する。
4. 検索、詳細の情報階層と操作性を見直す。
5. 部隊編成の共有・比較・整理を整備する。

### Update02 — 新兵科・兵科技能の横断検索

**予定表示版:** 3.2.0.0 Update02 rNNN

**状態:** 計画

**予定表示版:** 3.2.0.0 Update03 rNNN

**状態:** 計画

- 前回の検証済みデータと現在のデータを比較し、追加・変更・削除を区別する。

**予定表示版:** 3.2.0.0 Update04 rNNN

**状態:** 計画

- 検索モード、カテゴリ、状態変化、タグ、キーワードの条件要約を整理する。

## 4. 共通品質・リリースゲート

- 既存のアプリ検証スクリプトと関連回帰を実行する。新しいテストはアプリ検証へ組み込む。
- 生成JSON契約を変更する場合、クローラー正本から派生JSON一式を再生成し、アプリ側で個別編集しない。
- 検索・詳細・編成・保存互換・Export/Importを影響範囲に応じて回帰する。
- PC・スマートフォンの両方でレイアウトと操作を確認する。
- 変更ごとに開発ブランチへのpush、イベント駆動PreviewのActions、Preview markerと公開ページを確認する。
- Preview確認前に正式版へ反映しない。正式版反映は利用者承認を得て行う。
- Updateごとにroadmap、implementation、reportを更新し、確認事項・未解決事項を明記する。
