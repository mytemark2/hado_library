# 3.2.0.0 Update05 実装記録

## 1. 実装方針

既存の分割済みランタイムを拡張し、HTMLへ新規ロジックを埋め込まない。派生JSONと保存形式は変更せず、取得済みの技能説明から表示階層だけを組み直す。

## 2. 実装内容

### 2.1 詳細タブ

- 武将詳細を `基礎 → 戦法 → 技能 → 関連 → 変化率 → その他` の順へ変更した。
- 武将詳細の初期タブを `基礎` に変更した。
- 技能詳細を `内容詳細 → 変化率` の順へ変更した。

### 2.2 参照技能の親子表示

- 親技能カード内に `参照技能` グループを追加した。
- 参照技能へ「親技能名から付与」を表示した。
- `data-parent-skill` と `data-referenced-from` を追加し、親子関係を検証可能にした。
- 参照技能の抽出元を選択中技能レベルの説明に合わせた。
- 参照技能を各レベルの表示パネル内へ配置し、レベル切替時に親技能の説明と参照技能を同時に切り替えるようにした。

### 2.3 重複説明と補足

- 直接技能詳細で技能レベルパネルが表示される場合、同じ内容の条件・効果ブロックを再表示しない。
- 二次的な詳細テーブル・節は `補足情報` の折りたたみに格納した。
- スマートフォンの折りたたみ操作は44px以上の操作高さを確保した。

### 2.4 共通技能レベル解釈

- 武将詳細と技能詳細は `renderSkillLevelToggleForItem` を継続使用する。
- 部隊編成も同じ共通処理を継続使用する。
- 実在レベルだけを選択肢にする既存の全技能監査を維持した。

## 3. 変更しない範囲

- 一次JSON・派生JSON・索引
- 保存データ構造
- Export / Import形式
- 編成配置・評価ロジック
- Production・正式版設定

## 4. HTMLサイズと外部化

- `index.html`: 28,997 bytes → 28,997 bytes（0 bytes）
- HTML変更は既存外部アセットのキャッシュ識別子更新のみ。
- 新規動作は `hado_core.js`、表示は `hado_styles.css`、回帰は外部テストへ実装した。HTMLへの大型スクリプト追加はない。
