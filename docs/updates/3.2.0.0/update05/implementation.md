# 3.2.0.0 Update05 実装記録

## 1. 実装方針

既存の分割済みランタイムを拡張し、HTMLへ新規ロジックを埋め込まない。派生JSONと保存形式は変更しない。r219の重複説明抑止と共通技能レベル解釈を維持し、利用者動線をr220、一致元優先順位をr221で修正した。r222では公開Previewで残った固有名節の分類だけを追加補正する。

## 2. r220 利用者動線修正

### 2.1 タブと検索一致

- 武将タブをUpdate04時点の `概要 → 変化率 → 基礎 → 戦法 → 技能 → その他` へ復元した。
- 技能タブを `変化率 → 内容詳細` へ復元し、技能の初期表示は `内容詳細` を維持した。
- キーワード一致理由へ `keywordMatchTab` を保持し、検索結果選択時に該当タブを自動表示するようにした。
- 詳細上部へ検索一致理由と「一致箇所を表示」を追加した。
- 手動選択タブをカテゴリごとに保持し、操作履歴にも `detailActiveTab` を保存した。

### 2.2 常時表示の要約

- 武将詳細上部に兵科・天賦・おすすめ編制の要約を追加した。
- 詳細な能力値や五行適正は従来どおり基礎タブに残した。

### 2.3 参照技能の同一階層化

- 親技能内の `参照技能` 入れ子グループを削除した。
- 親技能と付与技能を同じカード一覧に表示した。
- 付与技能には `親技能名から付与` と `data-referenced-from` を残した。
- 武将詳細・技能直接詳細の双方で、技能レベル切替に連動する参照技能パネルを同一階層へ配置した。

### 2.4 維持したr219改善

- 直接技能詳細の同一説明重複抑止。
- 二次情報の `補足情報` 折り畳み。
- `renderSkillLevelToggleForItem` による武将・技能・編成の共通技能レベル解釈。
- 実在しない技能レベルの除外。

### 2.5 r221 公開Preview残件の補正

- r220公開Previewの `轟名` 検索で、検索用の `description` が画面内の技能節より先に一致し、概要タブが開くことを検出した。
- 一致理由候補の順序を、画面に表示できる節 → 表 → 検索用要約 → 生データの順へ変更した。
- 表は技能行、戦法表、基本情報表を内容から分類し、該当タブへ対応させた。
- 検索用要約と技能節の両方に同じ語があるfixtureを追加し、技能節が優先されることを回帰化した。

### 2.6 r222 固有名節の分類補正

- r221公開Previewで `轟名` の節見出しが一般節と判定され、概要タブが開くことを検出した。
- 節見出しを `getOwnedSkillLevelMapFromTables` の所有技能名と照合し、一致時は技能タブへ分類する。
- 節見出しを `findTacticName` の戦法名と照合し、一致時は戦法タブへ分類する。
- `轟名` と `強盛莫敵` の固有名節fixtureを追加した。
