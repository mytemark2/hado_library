# 3.2.0.0 Update05 — 内容詳細・技能表示の情報階層

## 1. 目的

武将詳細と技能詳細を、利用者が「基本情報 → 戦法 → 技能 → 関連情報」の順で読み、条件・効果・付与される参照技能の関係を迷わず追える表示へ整理する。部隊編成を含む技能レベル表示は既存の共通解釈を維持し、存在しないレベルと説明重複を出さない。

## 3. 開始時に確認した問題

1. 武将詳細の初期タブが「概要」で、基本情報・戦法・技能の順序が利用者の確認順と一致していない。
2. `LR袁紹` の技能 `轟名` が付与する `轟天Lv3` と `盟主Lv2` が親技能の外側に同列表示され、親子関係を視覚的に追いにくい。
3. 技能 `轟名` の直接詳細で、条件・効果の構造化表示と技能レベル説明に同じ文が二重表示される。
4. 長い補足情報が主説明と同じ強さで表示される。

## 4. 実装計画

1. 武将詳細タブを `基礎 → 戦法 → 技能 → 関連 → 変化率 → その他` に並べ、初期表示を `基礎` にする。
2. 参照技能を親技能カード内の `参照技能` グループへ入れ、親名を表示・DOM属性の両方で保持する。
3. 参照技能の抽出対象を選択中技能レベルの説明に合わせる。
4. 直接技能詳細は技能レベル説明を主表示とし、同一の条件・効果ブロックを重複表示しない。
5. 補足情報は `補足情報` の折りたたみへ移す。
6. 武将詳細・技能詳細・部隊編成が共通の技能レベル表示処理を使うことを回帰テストで固定する。

## 5. 完了条件

- 公開Previewで `3.2.0.0 Update05 r219` が表示される。
- 武将詳細は `基礎` が初期選択され、計画順にタブが並ぶ。
- `LR袁紹 → 轟名` で `轟天Lv3` と `盟主Lv2` が `轟名` の子として表示される。
- `轟名` の直接詳細で同じ条件・効果説明が二重表示されない。
- 選択可能な技能レベルは実在レベルのみで、選択レベルと説明が一致する。
- PC・スマートフォンで横はみ出しと操作欠落がない。
- App Validation、Actions、イベント駆動Preview同期、marker、公開URL実動作が合格する。
