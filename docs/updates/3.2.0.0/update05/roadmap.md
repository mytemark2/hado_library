# 3.2.0.0 Update05 — 内容詳細・技能表示の情報階層

## 1. 目的

検索・関連参照・編成判断で詳細画面を開いた利用者が、目的の情報へ追加の探索なしで到達できる表示にする。情報の出所順ではなく、利用者の操作目的を優先する。技能の付与関係は保持するが、付与技能を親技能の内側へ隠さず、最終的に有効な技能を一覧で確認できるようにする。

## 2. 利用者確認を受けた改訂

`3.2.0.0 Update05 r219` は実装・検証・Preview公開まで完了したが、公開後の利用者確認で次の問題が判明したため、2026-11-02に完了扱いを取り消した。r220で動線、r221で一致元の優先順位、r222で固有名節の分類を補正した。r222公開Previewの内蔵検証で、旧実装の関数文字列を照合する検証が新しい選択経路を誤判定したため、r223で実際の選択関数を実行する検証へ改める。

1. 従来先頭にあった「概要（関連）」と「変化率」を後方へ移し、利用者が判断情報へ到達する操作数を増やした。
2. 全カテゴリへ一律の読み順を適用し、検索一致箇所を最初に表示しなかった。
3. 参照技能を親技能内へ入れたため、最終的に有効な技能を一覧で把握しにくくした。

## 4. 修正計画

1. Update04時点の安定したタブ順を復元する。
   - 武将: `概要 → 変化率 → 基礎 → 戦法 → 技能 → その他`
   - 技能: `変化率 → 内容詳細`（初期表示は内容詳細）
2. キーワード一致理由へ一致先タブを保持し、検索結果選択時に該当タブを自動表示する。
3. 詳細画面上部にも一致理由を表示し、「一致箇所を表示」で該当タブへ戻せるようにする。
4. 武将の兵科・天賦・おすすめ編制を上部要約へ常時表示する。
5. 利用者が手動選択したタブをカテゴリごとに保持し、直接リンク・履歴復元で再利用する。
6. 参照技能を親技能と同じカード一覧へ戻し、`親技能名から付与` と `data-referenced-from` で由来を明示する。
7. 技能レベル変更時は、同一階層にある参照技能カードも同期する。
8. 重複説明抑止、補足情報の折り畳み、共通技能レベル解釈はr219の改善を維持する。
9. 一致理由は画面に表示できる節・表を検索専用の要約文より優先し、検索語を含む実表示タブを選ぶ。
10. 固有名だけの節見出しは、武将の戦法名・所有技能表と照合して戦法タブ・技能タブへ分類する。
11. 内蔵検証は関数文字列の旧実装断片を探さず、検索一致・記憶タブ・カテゴリ初期値の優先順位を実際の選択関数で検証する。
