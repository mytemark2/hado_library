# 3.1.0.0 r193 技能レベル単一選択・タググループ折り畳み Implementation

## 目的

- 技能レベル選択時は同じ技能の他レベル説明を閉じ、常に1レベルだけを表示する。
- 武将技能カードと部隊編成の技能名右側へ、現在有効な技能レベルを表示する。
- タグ選択画面はグループ見出しで候補の表示・非表示を切り替え、初期状態を全グループ非表示にする。
- タググループのカテゴリ表記を現在選択中の検索カテゴリへ合わせ、武将検索時は「武将」と表示する。
- EffectClauseから生成済みの「条件」「発動」タグをタグ選択グループへ確実に統合する。

## 実装

1. `hado_skill_level_toggle.js`
   - レベルボタンを単一選択の`radiogroup`として扱う。
   - 選択時に同一技能の他ボタンを非選択、他説明を非表示にする。
   - 選択中レベルの再クリックでは閉じず、1件表示を維持する。
2. `hado_core.js` / `hado_formation.js`
   - 武将技能、参照付与技能、部隊編成の技能見出しへ有効レベルを表示する。
3. `hado_status_effects.js`
   - タググループ見出しを開閉ボタンにする。
   - タグ画面を開いた直後は全グループを閉じる。
   - カテゴリ表示は現在有効な検索カテゴリとの共通部分を優先する。
   - 条件・発動タグの既存Clause統合を表示契約と診断へ固定する。
4. `hado_styles.css`
   - 技能レベル表示、タググループ開閉、スマートフォン操作領域を整える。

## 互換性

- 選択済みタグ、検索履歴、保存データ、Export/Importの形式は変更しない。
- 検索のタグ論理はグループ内OR、グループ間ANDを維持する。
- JSON、crawler、EffectClause schemaは変更しない。

## 再発防止

- 661技能・3,305レベル行の全件検査を維持する。
- 単一選択後に他説明が閉じることと、選択中レベルの再クリックで閉じないことを自動検査する。
- タググループの初期非表示、開閉状態、現在カテゴリ表示、条件・発動グループ統合をApp Validationで検査する。

## 外部化判断

既存の責務別JavaScriptへ実装し、HTMLにはキャッシュキー更新のみを行う。新しいインラインJavaScriptは追加しない。
