# 3.1.0.0 r198 選択タグハイライト配色修正 Implementation

## 目的

選択タグの対応色から青系・緑系を除外し、アプリ本体の配色と混同しないようにする。

## 実装

- `tag-color-0`から`tag-color-11`の背景・枠・文字色だけを、黄・橙・赤・桃・紫・茶系へ置換する。
- 色番号の割当、解除後の色維持、検索条件と該当箇所の対応、DOM構造は変更しない。
- 専用回帰で12枠の色値を固定し、青系・緑系が再混入した場合に検出する。

## 外部化判断

既存の`hado_styles.css`内の配色変数だけを変更する。新しいJavaScript、インラインCSS、HTML構造は追加しない。
