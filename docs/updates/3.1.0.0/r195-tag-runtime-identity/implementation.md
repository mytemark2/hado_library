# 3.1.0.0 r195 タグ画面投影の武将版違い混同修正 Implementation

## 目的

r194の公開画面で`発動:交戦開始時`が原文105武将ではなく179件となった画面投影キャッシュ漏れを修正する。

## 実装

1. `hado_clause_surface_bridge.js`
   - reviewed Clause照合用の広い武将キーと、画面投影キャッシュ用の完全一致キーを分離する。
   - レアリティ、覚醒、ORIGINS、兵科表記、読み仮名を保持した単位で検索タグをキャッシュする。
2. `tools/test_3_1_0_0_tag_search_exhaustive.js`
   - 直接の検索索引ではなく、実画面が使用するClause surface bridge経由で488武将・1,032タグを監査する。
   - LR馬良の`交戦開始時`がUR馬良へ漏れない代表回帰を追加する。

## 互換性

reviewed EffectClauseの広い名称照合、条件成立評価、検索論理、保存形式、JSON、crawlerは変更しない。画面投影キャッシュの識別単位だけを厳密化する。

## 再発防止

全タグ総点検を画面投影API経由へ変更し、索引が正しくても画面結合で所有者が増減する不具合をApp Validationで検出する。

## 外部化判断

既存の画面投影責務JavaScriptを修正し、HTMLには`r195`キャッシュキーのみ反映する。インライン実装は追加しない。
