# 3.1.0.0 r196 選択タグと該当箇所の色対応 Implementation

## 目的

選択済みタグ、検索結果が持つ対象タグ、結果・内容詳細内の該当文字を同じ色で対応付ける。複数タグは別々の色にし、どの条件による一致かを一覧上で判別できるようにする。

## 実装

1. `hado_tag_highlight.js`
   - 12色の色番号割当を一元化する。
   - タグを解除しても残ったタグの色番号を維持する。
   - 結果が実際に所有する選択タグだけを照合対象にする。
   - 文字列をHTMLエスケープしたうえで、タグ値の完全な文字列出現だけを`mark`へ変換する。
2. 検索UI
   - 選択済みタグ、折り畳み時の検索条件、選択画面のチェック済みタグを同色にする。
   - 通常・状態変化・型検索の結果カードへ、実際に一致した選択タグを同色で表示する。
   - PC結果カードの名称・補足・一致理由と、スマートフォン結果要約の該当文字を着色する。
3. 内容詳細
   - 選択中の結果が持つタグだけを対象にし、詳細内の該当文字を結果タグと同色にする。
   - 既存キーワードハイライトと重なった場合も、タグ値との完全一致時だけタグ色を付与する。
4. Preview同期
   - 新しい実行時JavaScriptを同期対象・SHA-256検証対象・存在確認対象へ追加する。

## 判定ロジックを変更しない範囲

タグのグループ内OR・グループ間AND、全タグ索引、検索カテゴリ投影、状態変化検索、型検索、保存形式、JSON、crawlerは変更しない。表示対象タグは既存の`_detailTags`と同じ所有判定から得る。

## 再発防止

専用テストで色番号の重複、タグ解除後の色維持、非所有タグの除外、複数色の文字列着色、HTMLエスケープ、PC・スマートフォン・内容詳細への接続、12色CSS、読み込み順を検証する。既存の939タグ総点検も同時にApp Validationへ残す。

## 外部化判断

色番号割当と安全な文字列処理を`hado_tag_highlight.js`へ外部化した。`index.html`は外部スクリプト宣言と`r196`キャッシュキーだけを追加し、大きなインライン処理は追加しない。
