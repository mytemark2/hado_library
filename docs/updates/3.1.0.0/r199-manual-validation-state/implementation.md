# 3.1.0.0 r199 手動検証の実行中表示誤判定修正 Implementation

## 目的

手動検証ボタン押下時の正当な実行中表示を回帰検証が欠落とみなし、正常なデータと画面をNGにする自己矛盾を解消する。

## 実装

- ページ全体の固定文言一覧から、状態によって変化する「検証実行」を除外する。
- `runValidationBtn`の現在値を要素単位で検証し、「検証実行」と「検証中…」だけを許可する。
- ボタン要素の欠落または未知の表示は従来どおり回帰NGに含める。
- 専用回帰で通常時、実行中、未知状態、要素欠落を固定し、全体検証へ常設する。

## 外部化判断

既存の検証責務を持つ外部`hado_bootstrap.js`内で修正する。HTMLへJavaScriptを追加せず、画面構造と実データは変更しない。
