# 3.1.0.0 r191 技能レベル表示改善 Implementation

## 利用者要件

- 技能レベルタグをクリック可能なトグルにする。
- タグをクリックすると、そのレベルの説明だけを表示・非表示にする。
- 武将・検索・部隊編成では、現在有効なレベルだけを初期表示し、他レベルは非表示にする。
- 一般技能と参照付与技能を同じ操作規則にする。

## 実装方針

- 共通の表示生成・開閉制御を`hado_skill_level_toggle.js`へ外部化する。
- 各レベルタグをbuttonとして出力し、`aria-controls`、`aria-expanded`、`aria-pressed`で対応説明と開閉状態を関連付ける。
- 武将・検索は所持・付与レベル、部隊編成は集計済みの有効レベルを初期表示レベルとして渡す。
- 各タグは独立して開閉でき、利用者が比較したい複数レベルを同時に表示できるようにする。
- 現在レベルを解決できない技能は、誤ったレベルを選ばず全レベルを閉じた状態にする。

## 適用範囲

- 武将の技能カード
- 通常検索・技能検索の技能カード
- 参照付与技能カード
- 技能詳細のレベル別説明
- 部隊編成の選択枠技能一覧

## 互換性・外部化

- JSON、crawler、保存schema、Import/Export形式、技能レベル集計ロジックは変更しない。
- HTMLへ実装コードを追加せず、新規外部JavaScriptと既存CSSへ分離する。
- 共有表示部品を使用できない場合は、従来の技能説明へフォールバックする。
- `HADO_DEV_INFO.json`は変更しない。表示版は`hado_version.js`だけで`3.1.0.0 r191`へ更新する。

## 再発防止

- 現在レベルのみ初期表示、他レベル非表示、独立トグル、一般表示・参照技能・部隊編成への接続を専用テストで固定する。
- 専用テストを`tools/run_app_validation.py`へ常設し、今後の共通表示変更でも回帰を検出する。
