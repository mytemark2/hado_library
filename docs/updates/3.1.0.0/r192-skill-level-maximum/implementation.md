# 3.1.0.0 r192 技能別最大レベル表示修正 Implementation

## 不具合分類

- 分類: データ意味解釈と表示契約の不備。
- 発生箇所: r191で追加した技能レベル共通トグル。
- 症状: 技能データの`-`行を未存在レベルではなく説明行として扱い、技能に存在しないレベルまでタグ表示した。

## 根本原因

正本技能データはレベル表の形をⅠ〜Ⅴで揃え、存在しないレベルを`-`で表している。r191の抽出処理はレベル名と空文字だけを検査し、`-`を有効な本文として通した。共通UIも渡された行を無条件に表示し、`-`を「説明なし」に置換したため、抽出層と表示層の両方で未存在レベルを拒否できなかった。

## 恒久対策

1. `hado_core.js`の共通レベル抽出で、空文字と各種ダッシュだけの行を未存在として除外する。
2. `hado_skill_level_toggle.js`でも、説明本文もHTMLもない行とダッシュだけの行を拒否する。
3. 現在レベルが技能の実在最大レベルを超える場合は、実在する直近下位レベルへ解決する既存処理を維持する。
4. 「説明なし」を生成して未存在レベルを見せる経路を廃止する。

## 全件監査

- 正本技能: 661件
- 正本レベル行: 3,305件
- 効果説明が実在するレベル: 1,661件
- 未存在プレースホルダー: 1,644件
- 未存在プレースホルダーを含む技能: 528件

専用回帰は661技能を毎回走査し、表示レベル集合が「説明が実在するレベル集合」と完全一致することを検証する。白眉や貞良だけを個別修正する分岐は作らない。

## 適用範囲・互換性

- 武将の技能、検索、参照付与技能、技能詳細、部隊編成の選択枠技能に同じ抽出規則を適用する。
- JSON、crawler、技能レベル集計、保存schema、Import/Export形式は変更しない。
- HTMLへ実装を追加せず、既存の外部JavaScriptを修正する。
- `HADO_DEV_INFO.json`は変更しない。表示版は`hado_version.js`だけで`3.1.0.0 r192`へ更新する。
