# 3.1.0.0 r204 個別状態変化検索の最大技能レベル索引補完

## 分類と原因

- 不具合分類: 個別状態変化検索の検索漏れ。
- 原因: 通常の技能本文は全データ・最大段階で評価する一方、参照付与技能は付与時に指定されたLvだけを武将本文へ展開していた。個別の状態変化検索が生成済み状態変化グループ所有者索引を参照しないため、参照技能の最大レベルで成立する所有関係を検索結果に反映できなかった。
- 代表例: LR張角の「天公」は「大賢Lv3」を付与するが、「大賢」の感電回避記述はLvⅣにある。全データ・最大では個別検索にLR張角が含まれるべきである。

## 実装

- 個別状態変化検索に、選択中の効果名・グループに一致する生成済み所有者索引の結果を統合する。
- 索引補完は全データかつ技能段階「最大」のときに限定し、初期段階・保存データには適用しない。
- 既存の直接検索結果が同じ効果を持つ場合は重複追加しない。
- 技能段階切替時に実行中の状態変化検索を再実行し、個別検索キャッシュにも技能段階を含める。
- 回帰テストでLR張角、効果名の完全一致、初期段階・保存データでの非適用、重複抑止を固定する。

## 影響範囲

個別状態変化検索の全カテゴリ、状態変化グループ検索との共通索引、技能段階切替時の検索更新。保存データ形式、JSON契約、戦法・技能データ、編成計算、通常検索の意味は変更しない。

## ファイル・配布

- `hado_search.js`: 索引照合と個別結果の統合。
- `hado_core.js`: 技能段階切替時の検索再実行。
- `tools/test_individual_status_effect_max_level_owner_index.js`: 回帰テスト。
- `tools/run_app_validation.py`: 回帰テストを標準検証へ追加。
- `hado_version.js`、`index.html`、現行revisionを検証するテスト: Preview revision r204とキャッシュキー。
- HTMLサイズ差分: index.htmlの改訂前後で同サイズ（cache keyの数字置換のみ）。
- 外部化: 検索処理は既存の外部JavaScriptへ実装し、HTML内へ処理を追加しない。
