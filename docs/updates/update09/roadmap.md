# Update09 Roadmap

## 目的
Update08までに実装した型編成ナビ、候補トレイ、保存データ連携、部隊編成評価を、実戦で迷わず・軽く・見やすく使えるUI/UXへ整理する。

## 現在の状態
- 状態: Phase 3実装済み（最新: `3.0.0.0 Update09.3.13` / revision 46。Phase 4・Phase 5は未完了）
- 調査開始HEAD: `779c15c5193949a2122004f2cbbf297f969a8ca9`
- 現在反映HEAD: `466f62f931e5accd827870c809db4082e5c0f1f2`（preview同期元commitとして確認済み）
- 対象ブランチ: `feature/app-3.0.0.0`
- Update08最新状態: `Update08.23`（型候補描画キャッシュと重い診断の遅延化まで完了）
- Update09表示ルール: Phaseが分かるように `Update09.x.y` で表示する（`x` はフェーズ番号、`y` は当該フェーズ内の改修回数）。

## 優先テーマ
1. 部隊編成画面と型編成ナビ/型候補一覧の体感性能改善。
2. 部隊編成のレイアウト整理と、武将・装備変更のダイアログ/ポップアップ化の完成。
3. ガイドの最新化と、必要な時だけ読める段階的な説明表示。
4. 補足説明の常時表示を減らし、画面密度を下げる。
5. 型編成ナビ → 型候補一覧 → 候補トレイ → 部隊編成の操作導線を直感化する。
6. PC/スマホそれぞれの表示破綻、はみ出し、操作困難箇所を回帰確認する。

## 完了条件
- 課題ごとにユーザー受け入れ操作を定義し、実装後にPC/スマホ双方で確認する。
- HTMLへ大型ロジックを追加せず、既存責務の外部JS/CSSへ統合する。
- 型検索は候補提示、組み合わせ検討は部隊編成画面という設計を維持する。
- 既存の成立ゲート、保存データ互換、Export/Import互換を維持する。
- Update09の実装内容、HTMLサイズ増減、外部化判断、検証結果、プレビュー同期結果を記録する。

## フェーズ計画

### Phase 1: UI/UX監査と改善案整理（完了）
- 現行実装とUpdate08.23の残課題を確認した。
- 問題点を性能、部隊編成レイアウト、ガイド、補足説明、操作導線の5分類で整理し、各項目に3案ずつ改善案を作成した。
- 実装順序は、性能改善 → 部隊編成ポップアップ化 → 導線統合 → ガイド/説明整理 → PC/スマホ回帰とした。

### Phase 2: 性能・再描画改善（完了）
- 部隊編成の状態変化率/合算技能計算結果を、編成内容・保存データ・関連マスタ件数から作る署名でキャッシュするようにした。
- 部隊編成のタブ切替、ダイアログ開閉、選択スロット変更など、編成内容が変わらない再描画では重い再計算を避けるようにした。
- 型候補一覧では、ロール別のスコア計算・所有判定結果を検索語なしのベースキャッシュへ分離し、検索欄入力時は文字列フィルタだけを行うようにした。

### Phase 3: 部隊編成レイアウトと変更ダイアログ完成（実装済み、最新: Update09.3.13）
- 武将/装備変更をPCでもモーダル/ポップアップ中心に寄せた。
- 編成盤面、選択中スロット、結果サマリー、部隊一覧の優先順位を整理した。
- 候補トレイからの配置先選択は、既存選択ダイアログへ自然につなげる設計を維持した。
- 部隊編成のグループ行は、グループ名と主要ボタンを含めて1行表示へ整理した。グループ名変更、新規作成、削除は別ダイアログで行う。
- 型選択は型名中心の表示へ整理し、表示型IDの通常UI表示を廃止した。
- トータルスコアや評価スコアは入力ダイアログにせず、自動計算の読み取り専用表示へ変更した。
- 履歴へ保存ボタンは廃止し、保存ボタン押下時に現行内容と自動計算スコアを保存する方針へ整理した。マイメモは1行表示にし、編集時のみ別ダイアログで編集する。
- 型候補一覧の適合スコアは、対象武将が対象型の5条件に一致する状態変化率項目数の合計として扱う。
- 部隊編成のトータルスコアは、選択部隊メンバーの5つの評価スコア行の合計として扱う。各評価スコア行は、選択中の型の5条件に一致する状態変化率項目数を集計する。
- Phase 3.12〜3.13で、部隊編成スコアパネルの評価スコア定義を修正し、ヘッダーには誤解を招く集約評価スコアを出さず、展開行を評価スコアとして表示する構成へ合わせた。
- スマホ部隊編成では、見える順番を `軍馬 → トータルスコア → 結果サマリー` に整理し、トータルスコアは展開式の `details` 表示にした。
- previewには `3.0.0.0 Update09.3.13` として同期され、`feature/app-3.0.0.0` の反映HEADと一致することを確認済み。

### Phase 4: ガイド・補足説明・導線整理（未完了）
- スタートガイド、型編成ナビ、型候補一覧、部隊編成内の文言をUpdate09時点へ最新化する。
- 長い補足は `details`、ヘルプアイコン、モーダルに移し、常時表示は短い行動ラベルへ絞る。
- 全データ表示/保存データ表示の差と、次に押すべきボタンを画面上で明確にする。
- 現時点では、preview上のスタートガイドに旧世代の `2.9.6 操作ガイド` 表示が残っているため、Phase 4の最初の修正対象とする。

### Phase 5: 回帰・プレビュー確認（未完了）
- JavaScript/JSON/HTML/CSS/ワークフロー検証を実行する。
- PC/スマホの主要導線、保存データImport/Export、型候補からの新規部隊、候補トレイ配置を確認する。
- Push後のpreview同期と公開commit一致を確認する。
- Phase 3.13時点ではpreviewのバージョン同期は確認済みだが、PC/スマホの実操作回帰を含むPhase 5完了判定はまだ行わない。
