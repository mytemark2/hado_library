# Update11 Roadmap

## 目的

検索用タグを対象カテゴリ別に理解できる表示へ整理し、状態変化検索でもタグを併用できるようにする。技能タグの所有者検索修正は `3.0.1.0 Update11.1 r161`、タグ操作改善は `3.0.1.0 Update11.2 r162`、スマホ表示改善は `3.0.1.0 Update11.3 r163`、PC/スマホ機能差解消は `3.0.1.0 Update11.4 r164` とする。

## 対象

1. タグ索引の各項目からタググループと対象カテゴリの対応を構築する。
2. タググループに対象カテゴリ名を表示し、検索カテゴリと同じ順序で並べる。
3. 状態変化選択とタグ入口を同一行へ配置する。
4. 状態変化検索の同期・非同期・グループ索引・キャッシュ・履歴へタグ条件を反映する。
5. 通常検索と型検索の既存タグ仕様（グループ内OR、グループ間AND）を維持する。
6. 技能タグを技能項目だけでなく、技能所有者索引に記録された武将・装備へ反映する。
7. 技能タググループの対象カテゴリ表示を「武将・技能・装備」にする。
8. タグ候補の選択または有効タグの完全一致入力でタグを自動追加する。
9. 「追加」ボタンを削除し、PC・スマホのタグ入力行を「タグ・入力・クリア」の3列にする。
10. IME変換中は追加せず、無効入力は保持し、重複タグでは検索再実行と履歴追加を行わない。
11. タグ選択結果を先に描画し、その次の描画機会から検索を開始する。連続操作では古い予約検索を破棄する。
12. スマホのテキスト入力を16px以上とし、iOSのフォーカス時自動拡大を防ぐ。
13. 429px以下では状態変化2選択を1段目、解除とタグ入口を2段目へ配置し、選択済みタグと件数を折り返して全表示する。
14. 状態変化検索へ通常検索と同一のタグ入力コンボボックス、タグ一覧、クリア操作を提供する。
15. PCでは状態変化条件とタグ入力を同一行にし、980px以下では横幅に合わせて安全に2段へ折り返す。
16. スマホ検索結果の選択欄直下へ、PCカードと同じ主要badge・一致理由の要約を表示する。
17. スマホ部隊編成で、選択枠の有効技能を開閉表示し、参軍選択時に現在の有効技能名を表示する。
18. スマホ部隊編成で、軍馬の編成先・種別・固有技能・通常技能を表示し、520px以下は1列配置にする。
19. 軍馬画面の `assignedCount` 未定義エラーを解消し、スマホ検索履歴は検索タブだけに表示する。
20. スマホのテキスト入力・セレクト・テキストエリアを16px以上とし、viewportのズーム禁止を使わずフォーカス時自動拡大を防ぐ。

## 完了条件

- 専用回帰と全App Validationが成功する。
- PCと320px・375px・390pxで状態変化・タグ行、タグ候補、選択済みタグ、横はみ出しを確認する。
- Pull Request、Actions、イベント駆動Preview同期、公開URLとmarker一致を確認する。
