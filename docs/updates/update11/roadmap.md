# Update11 Roadmap

## 目的

検索用タグを対象カテゴリ別に理解できる表示へ整理し、状態変化検索でもタグを併用できるようにする。技能タグの所有者検索修正は `3.0.1.0 Update11.1 r161` とする。

## 対象

1. タグ索引の各項目からタググループと対象カテゴリの対応を構築する。
2. タググループに対象カテゴリ名を表示し、検索カテゴリと同じ順序で並べる。
3. 状態変化選択とタグ入口を同一行へ配置する。
4. 状態変化検索の同期・非同期・グループ索引・キャッシュ・履歴へタグ条件を反映する。
5. 通常検索と型検索の既存タグ仕様（グループ内OR、グループ間AND）を維持する。
6. 技能タグを技能項目だけでなく、技能所有者索引に記録された武将・装備へ反映する。
7. 技能タググループの対象カテゴリ表示を「武将・技能・装備」にする。

## 完了条件

- 専用回帰と全App Validationが成功する。
- PCと390x844で状態変化・タグ行、タグ候補、横はみ出しを確認する。
- Pull Request、Actions、イベント駆動Preview同期、公開URLとmarker一致を確認する。
