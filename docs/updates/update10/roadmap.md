# Update10 Roadmap

## 目的

Update09完了版を起点として、正式版候補に必要な全体回帰、操作ガイドの最新化、配布・Previewの再現性を確認する。

## 開始基準

- 起点commit: `fba2f1999f8f821002931ff2413f4f43cae0983f`
- 起点表示版: `3.0.0.0 Update09.5.65 r155`
- 対象ブランチ: `feature/app-3.0.0.0`
- 状態: Update10.1・Update10.2 完了（公開Preview確認済み）。Update10.3はガイド視認性・画面同期を改修中。Update10全体の正式配布物監査と`main`反映判断は継続する。

## Update10.1 — タブ視認性と切替フィードバック

1. 共通デザイントークン、ARIA状態同期、ロービングフォーカス、キーボード操作を外部 `hado_tabs.js` に集約する。
2. 上位3画面と検索モードへ、形・塗り・選択表示・現在表示文脈を適用する。
3. 内容詳細、部隊編成内、候補ワークスペース、型編成ナビのタブへ同じ視覚言語とtabpanel関係を適用する。

第1〜3段階は完了した。選択状態はタブ自身の面・輪郭・太字・選択記号で示し、表示領域を圧迫する「〇〇を表示中」補助行は追加しない。

完了条件は専用回帰、全App Validation、PC/390x844実操作、Actions、公開Preview・marker一致である。すべて確認済み。

## Update10.2 — 操作ガイド最新化

1. スタートガイドを、データ準備、3検索モード、型編成ナビ、候補ワークスペース、部隊作成、6項目結果サマリーの現行順序へ同期する。
2. 検索ガイドへ、モード別状態保持、IME確定検索、符号直後の数値境界、型編成ナビ3入口、候補編集状態の復元、詳細タブを反映する。
3. 部隊編成ガイドへ、6項目結果サマリーと加算値の根拠表示、変化率タブの確認順序を反映する。
4. ガイド動作は外部 `hado_core.js` に維持し、専用回帰を全App Validationへ追加する。

完了条件は専用回帰、全App Validation、PC/390x844実操作、Actions、公開Preview・marker一致である。

## Update10.3 — ガイド視認性と画面同期

1. ガイド本文と見出しの行間・文字間隔をPC/スマホ共通で読みやすくする。
2. 初回ガイド開始時は検索タブの通常検索へ移動する。
3. 検索ガイド8番目は通常検索へ戻してから候補ワークスペース導線を説明する。
4. 部隊編成ガイド8番目は、PC/スマホ用に重複するDOMから表示中の結果サマリーを選択する。
5. 対象解決の共通処理と専用回帰を追加し、同じセレクターの先頭が非表示でも後続の表示要素を選べることを検証する。

完了条件は専用回帰、全App Validation、PC/390x844実操作、Actions、公開Preview・marker一致である。

## 初期スコープ

1. 通常検索、状態変化検索、型検索、詳細表示、部隊編成、保存Export/Importの全体回帰。
2. 全データ・保存データの双方で、型編成ナビ、9役割候補、候補ワークスペース、既存成立ゲートを確認。
3. PC、390x844スマホ、`file://`、公開Previewで主要操作を確認。
4. ガイド、版数表示、Debug Log、Preview marker、開発記録を現行機能に同期。
5. 配布対象が必要になった場合は、JSON一式、ZIP実展開、SHA-256、HTML一致を監査。

## 受入基準

- 新規または既知の不具合は、分類、根本原因、影響範囲、恒久対策、回帰防止、最小受入操作を記録する。
- 実装変更は外部JavaScript/CSSへ配置し、HTMLを肥大化させない。
- JSON契約に影響する変更はクローラー出力一式を正本として扱い、`node tools/test_json_index_contract.js` を実行する。
- 各変更はApp Validation、イベント駆動Preview同期、公開Pages、marker、PC/スマホ実操作まで確認する。
- `main` への正式反映候補とする前に、未確認項目・既知不具合・配布物監査結果を `report.md` に明記する。
