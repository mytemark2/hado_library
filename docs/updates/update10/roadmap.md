# Update10 Roadmap

## 目的

Update09完了版を起点として、正式版候補に必要な全体回帰、操作ガイドの最新化、配布・Previewの再現性を確認する。

## 開始基準

- 起点commit: `fba2f1999f8f821002931ff2413f4f43cae0983f`
- 起点表示版: `3.0.0.0 Update09.5.65 r155`
- 対象ブランチ: `feature/app-3.0.0.0`
- 状態: 準備完了。個別の実装・回帰ケース選定は未着手。

## 初期スコープ

1. 通常検索、状態変化検索、型検索、詳細表示、部隊編成、保存Export/Importの全体回帰。
2. 全データ・保存データの双方で、型編成ナビ、9役割候補、候補ワークスペース、既存成立ゲートを確認。
3. PC、390x844スマホ、`file://`、公開Previewで主要操作を確認。
4. ガイド、版数表示、Debug Log、Preview marker、開発記録を現行機能に同期。
5. 配布対象が必要になった場合は、JSON一式、ZIP実展開、SHA-256、HTML一致を監査。

## 受入基準

- 新規または既知の不具合は、分類、根本原因、影響範囲、恒久対策、回帰防止、最小受入操作を記録する。
- 実装変更は外部JavaScript/CSSへ配置し、HTMLを肥大化させない。
- JSON契約に影響する変更はクローラー出力一式を正本として扱い、`node tools/test_json_index_contract.js` を実行する。
- 各変更はApp Validation、イベント駆動Preview同期、公開Pages、marker、PC/スマホ実操作まで確認する。
- `main` への正式反映候補とする前に、未確認項目・既知不具合・配布物監査結果を `report.md` に明記する。
